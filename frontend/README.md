# Frontend

**Implemented — at the repository root, not here.**

The planning phase reserved this folder for a future Next.js app. That app is now the whole repository:

- `app/` — routes, dashboard pages, API handlers
- `components/` — the shell and shared UI (`components/data/` for provenance-aware widgets)
- `lib/` — connectors, reference layers, advisor logic
- `hooks/`, `context/` — live-data fetching and the farmer workbench context

Run it with `npm install && npm run dev`. This placeholder stays only so the old structure does not confuse a reader; nothing belongs in it.
